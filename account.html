JavaSE Project

Computerized Accounting Desktop Application

This accountant-focused desktop application boasts a comprehensive suite of financial features, including daybook, trial balance, balance sheet, journal, and profit-loss statements. Users can easily track their financial progress, prioritize products, and conduct transactions with a fixed product catalog using either cash or credit. Key functionalities encompass secure login, signup processes, selling, purchasing, chart generation, pay-in, payout, and diverse reporting tools. The user-friendly system also includes a help feature for inquiries and an about section for additional information, streamlining financial tasks and offering accountants an efficient decision-making tool.

Functional Requirements

  1. User Authentication: Implement a secure login and signup system for user authentication.

  2. Financial Management: Develop modules for daybook, trial balance, balance sheet, journal, and profit-loss statements.

  3. Product Transactions: Record buying and selling transactions of fixed products, allowing users to manage their inventory.

  4. Payment Options: Enable users to make transactions using both cash and credit.

  5. Reporting:Implement various reporting tools to generate charts and reports for informed decision-making.

  6. Transaction RecordingEnsure accurate recording of pay-in and payout transactions, reflecting in the journal and trial balance.

Non-functional Requirements

  1. User Interface (UI): Design an intuitive and user-friendly interface using Swing UI for a smooth user experience.

  2. Security: Implement robust security measures to safeguard user data and financial information.

  3. Performance: Optimize the application for efficient performance, even with some volume of transactions.

  4. Scalability: Design the system to handle potential future expansion and increased user activity.

P.S. This project is Second Year Project and participated in project show.
